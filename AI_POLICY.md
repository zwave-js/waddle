# AI policy

We welcome AI tools, including large language models, as aids when contributing
to Z-Wave JS projects. Contributors remain responsible for everything they
submit. Maintainers remain responsible for everything the organization merges
and releases. We hold all contributions to a high standard.

Maintainers dedicate their time and expertise to reviewing contributions.
Submitting AI-generated content that you have not personally reviewed,
understood, and verified wastes that time and will not be accepted.

## Autonomous agents

**We do not allow autonomous agents to contribute to Z-Wave JS projects.** We
will close pull requests or issues that we believe were created autonomously.
We may mark automated comments as spam. This rule also applies to contributions
that bypass the provided issue or pull request templates.

## Communication on issues, pull requests, and code reviews

You may use AI tools to help you write. Do not allow tools to post unreviewed
content on your behalf. Keep responses to the minimum needed to communicate
your intent. We may hide comments that appear to be unreviewed AI output.

When you open a pull request, you must be able to explain the proposed changes
in your own words. This requirement includes the pull request description and
responses to questions. If AI helped generate a pull request summary, review it
for technical accuracy before posting it.

**Do not use AI to generate the substance of answers to questions from
maintainers.** You must understand and be able to explain your own work. AI may
help improve grammar or clarity.

If you include context from an AI interaction in a comment, put it in a quote
block and disclose that it came from AI. Add your own explanation of its
relevance and implications. Do not share long excerpts.

## Non-native English speakers

AI can help people communicate in a language that is not their first language.
You may use it to improve the grammar or clarity of text you wrote. If AI
translates your comments, verify that the translation accurately reflects your
intent. You may include your original text in a details block. This helps
maintainers verify the translation and keeps the conversation readable.

## Code and documentation contributions

AI can help write code and documentation. Z-Wave JS requires a human reviewer
who understands any work produced with AI assistance.

Review, understand, and verify every contribution before submitting it. You
must be able to explain every code and documentation change in your pull
request. We will close pull requests that appear to contain unreviewed AI
output.

## Maintainer use of AI

Some Z-Wave JS projects use AI tools to assist with code reviews, issue triage,
reporting, and other project management tasks. These tools may comment on pull
requests or issues. Their output can be incorrect.

Treat a comment from an AI tool like any other review comment. If it is
incorrect, say so and give a brief explanation. Maintainers have the final say.
Ask a maintainer if you are unsure.

## Enforcement

We will close contributions that do not follow this policy. Repeated violations
may result in a block from contributing to Z-Wave JS projects. If you believe
your contribution was closed in error, contact a maintainer to discuss it.

This policy is adapted from the
[Open Home Foundation AI policy](https://developers.home-assistant.io/docs/ai_policy).
